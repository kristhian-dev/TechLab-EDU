# Ícones do TechLab EDU

Todos os ícones das telas usam agora arquivos locais da pasta `assets/` 
(as URLs do Flaticon CDN foram removidas — os tokens expiravam e as imagens quebravam).

## Mapeamento por pasta

| Pasta | Uso | Exemplos |
|---|---|---|
| `assets/icons-login/` | Tela de login/cadastro e campos de formulário | `user.png`, `mail.png`, `padlock.png`, `eye.png`, `eye-off.png`, `graduate-blue.png`, `user-blue.png`, `google.svg`, `microsoft.svg` |
| `assets/Icons-NavBar/` | Menu lateral das páginas | `home.png`, `target.png`, `ranking.png`, `conquistas.png`, `settings.png`, `logout.png`, `relatorio.png`, `multiple-users-silhouette.png` |
| `assets/icons-dashboard/` | Cabeçalho, métricas e cards dos dashboards | `lupa.png`, `bell.png`, `account.png`, `level-up.png`, `trophy.png`, `mission-*.png`, `target-*.png`, `multiple-users-silhouette-*.png`, `sala-techLabDU.png`, `sinal-de-seta-para-baixo-para-navegar.png` |
| `assets/icons-perifericos/` | Laboratório e cards de desafio | `CPU.png`, `Cooler.png`, `placa-mae.png`, `temperature.png`, `monitor-sem-sinal.png`, `Tela-erro.png` |
| `assets/logo/` | Logotipo | `Logo_TechLabEDU.png` |

## Referência nas telas

- Arquivos PHP/JS em `views/` referenciam os assets com o caminho relativo `../../assets/...`.
- `configuracoes/icones.php` define constantes `ICON_*` com caminhos a partir da raiz (`/assets/...`), usadas nas telas de login/cadastro.
